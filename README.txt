villiura.nails — файли для деплою
==================================

У ЦІЙ ПАПЦІ:
- index.html          — увесь сайт, один файл. Усі фото й відео підвантажуються
                         з Cloudinary за посиланнями, тому файл легкий (~90 КБ).
- favicon.ico          — іконка сайту (про всяк випадок окремим файлом; у сам
                         сайт вона вже вбудована, підключати додатково не треба).
- villiura-icon-512.png — та сама іконка більшого розміру (для соцмереж/аватарок).
- villiura-og-image.jpg — картинка-прев'ю для соцмереж (Telegram/Instagram/FB).
                         Ще НЕ підключена до сайту — див. пункт 3 нижче.


ЯК РОЗМІСТИТИ САЙТ ОНЛАЙН (найпростіший спосіб — Netlify, безкоштовно):

1. Зайди на https://app.netlify.com/drop з комп'ютера.
2. Перетягни файл index.html у вікно браузера (можна перетягнути всю папку,
   Netlify сам знайде index.html).
3. За кілька секунд отримаєш робоче посилання виду
   https://якась-назва.netlify.app — сайт уже онлайн.
4. За бажанням: у налаштуваннях Netlify можна підключити власний домен
   (наприклад villiura.nails), якщо його купиш.


ЩО ДОРОБИТИ ПІСЛЯ ТОГО, ЯК З'ЯВИТЬСЯ АДРЕСА САЙТУ:

1. og:url — у файлі index.html є рядок:
     <meta property="og:url" content="TODO-додати-URL-сайту">
   Заміни TODO-додати-URL-сайту на реальну адресу (наприклад
   https://villiura-nails.netlify.app/ або https://villiura.nails/).

2. og:image — залий villiura-og-image.jpg на Cloudinary (так само, як інші
   фото), скопіюй пряме посилання і встав його замість рядка:
     <meta property="og:image" content="TODO-додати-посилання-на-зображення-1200x630.jpg">

3. GA4 / Meta Pixel (якщо потрібні) — у файлі є мітки:
     <!-- GA4: вставити тег тут -->
     <!-- Meta Pixel: вставити тут -->
   Встав туди коди зі своїх кабінетів Google Analytics / Meta Business Suite.


ПІСЛЯ ДЕПЛОЮ — ОБОВ'ЯЗКОВО ПЕРЕВІР:

- PageSpeed Insights: https://pagespeed.web.dev — встав адресу сайту,
  подивись Performance / Accessibility / Best Practices / SEO.
- OG-прев'ю: https://opengraph.xyz — встав адресу сайту, перевір, як
  посилання виглядатиме в Telegram/Instagram (запрацює коректно лише
  після того, як заповниш og:url і og:image з пунктів вище).
